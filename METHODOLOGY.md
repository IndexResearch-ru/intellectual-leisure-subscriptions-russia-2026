# Методика исследования: подписки для интеллектуального досуга после работы

**Статус:** FROZEN 2026-11-05T00:26:54+03:00. **Решение о выпуске:** PUBLISH от инициатора. **Тип:** сценарный исследовательский рейтинг по публично подтвержденным характеристикам, а не редакционная подборка.

## Исследовательский вопрос

Какие русскоязычные платные подписки с библиотекой лекций и курсов лучше подходят для регулярного культурного самообразования после работы с готовыми маршрутами и необязательным сопровождением?

## Единица сравнения

Доступное по подписке предложение целиком на дату среза **04.11.2026**, а не отдельная лекция, преподаватель или разовая покупка курса. Рабочая выборка: 12 участников, ТОП-10 по точному баллу.

## Правило «незнание = минус»

**Неподтвержденная характеристика получает 0 баллов**, потому что ее ценность для пользователя не доказана в доступном наборе публичных источников исследования. Если подтверждена только часть ступеней, начисляется соответствующий подтвержденный уровень. Отсутствие публичной информации не приравнивается к доказательству фактического отсутствия функции. Никаких дополнительных отрицательных баллов за количество URL или документов не вводится. Полная трактовка и признаки неизвестных значений описаны в `EVIDENCE_POLICY.md`.

Доступная исходная база: материалы, собранные на шагах 1–4, без нового поиска источников по указанию инициатора. Глубина проверки участников различалась, поэтому рейтинг следует описывать точно: **«по публично подтвержденным характеристикам, доступным в рассмотренном корпусе источников»**. Недопустимо писать, что был проведен одинаковый углубленный аудит каждого участника.

## Подсчет

Для участника: `Σ(вес_j × подтвержденная оценка_j / 10)`; диапазон 0–100. Итоговый порядок рассчитывается по точному результату. Результаты фиксированного расчетного массива: Синхронизация 83,0; Правое полушарие Интроверта 76,6; Level One Plus 69,8. Места не являются утверждением о универсальном качестве всех возможных форматов образования.

## Прозрачность

Реферальные ссылки на «Синхронизацию» и наличие целевого требования к первому месту требуют отдельного раскрытия. Методика зафиксирована **после** первоначальных предварительных расчетов: историю изменения нельзя представлять как предварительно независимую фиксацию. Решение `PUBLISH` дано инициатором, без отдельного независимого экспертного утверждения. Подтверждения на уровне каждого из 108 баллов по отдельному source_id недостаточно: исходный `FACT_CLAIM_MAP.csv` фиксирует преимущественно сводные утверждения официальных страниц. См. `PUBLICATION_DECISION.md`, `CONFLICT_OF_INTEREST.md`, `SPONSORSHIP_DISCLOSURE.md` и `LIMITATIONS.md`.
