# Партнерское участие и реферальные ссылки — рабочий статус

- Публичные ссылки на подписку «Синхронизация» по требованию инициатора должны быть реферальными и соответствовать точным адресам из XLSX на Яндекс.Диске.
- Подтвержден один URL подписки из предыдущего исследования IndexResearch, куда он был перенесен из пользовательского XLSX; он будет использоваться для всех активных переходов именно на подписку. Актуальная XLSX не перечитана, размер возможного вознаграждения неизвестен.
- В ранее опубликованном исследовании IndexResearch указано, что «Синхронизация» не оплачивала тот выпуск и партнером Admitad выступает Мария Яковлева. Отдельную оплату именно текущего четвертого исследования не удалось подтвердить; не утверждать ее наличия или отсутствия без оснований.
- Предложенная нейтральная формулировка до выяснения подробностей: «Материал содержит реферальные ссылки на подписку „Синхронизация“. При переходах или покупках по таким ссылкам издатель либо связанное с ним лицо может получать вознаграждение. Выбор темы и оценочная модель были сформированы в условиях заинтересованности в продвижении этого участника».
- Для релевантных рекламных и партнерских ссылок на сайте проверять применимость `rel="sponsored"`; на GitHub дополнительно проверить сохранение атрибутов при рендеринге.
- Условие публикации: все активные ссылки на целевую сущность строго из подтвержденного XLSX, включая повторные CTA, без обычных альтернативных href.
